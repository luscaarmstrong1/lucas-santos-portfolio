## 📌 Sobre

Website e portfólio profissional de **Lucas Silva Santos**, desenvolvido com arquitetura editorial de alto padrão, animações coreografadas em GSAP, tipografia monumental e design responsivo impecável.

A experiência conecta o rigor técnico da engenharia elétrica e da energia solar à capacidade analítica de ciência de dados, desenvolvimento de software e automação de processos.

  - TCC em dispositivo de medição inteligente IoT para sistemas fotovoltaicos.
  - Iniciação científica em automação com Controladores Lógicos Programáveis (CLP).
- **Pós-graduação em Energia Solar Fotovoltaica** : UNINTER
  - Especialista em sistemas fotovoltaicos, geração distribuída (GD/MMGD), subestações BT/MT e proteção.
- **Pós-graduação em Ciência de Dados e Inteligência Artificial** : UNINTER *(Em andamento)*
  - Aprendizado de máquina, modelagem analítica, simulações computacionais e automação de pipelines.

## 💻 Como Executar Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) versão 18 ou superior
- `npm` instalado

### Instalação

```bash
# Clone o repositório
git clone https://github.com/luscaarmstrong1/lucas-santos-portfolio.git

# Acesse o diretório
cd lucas-santos-portfolio

# Instale as dependências
npm install
```

### Desenvolvimento

```bash
# Inicie o servidor de desenvolvimento
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador.

### Build de Produção

```bash
# Gere a versão otimizada de produção
npm run build

# Inicie o servidor em modo produção
npm start
```
